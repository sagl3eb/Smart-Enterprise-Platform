MMXXVI · Issue One

Four rooms in the same house.

These four concepts explore the emotional range of the Smart Enterprise Platform — sharing one palette (deep purple, lavender, cream) and one typographic voice (Fraunces + Mulish), but each expressing a different mood for a different moment in the product.

Why a showcase?

SEP is a serious tool for serious work. These pages exist to prove the brand can be expressive without losing clarity — to sit beside the app, not replace it, and to give stakeholders something to react to.

How to read it

Each page is a different moment: signing in, scanning the day, asking for help, telling the world about it. Open them in order — the palette carries you through.

One palette

Deep purple #5B21B6, ink #13102A, cream #F1EEFF — the exact values used inside the SEP app.

One voice

Fraunces for display, Mulish for body, JetBrains Mono for metadata — the same stack the app ships with.

Different moods

Login is reverent, dashboard is serious, chatbot is focused, landing is declarative.

How to use

Share with stakeholders. Pick the directions that feel right. The production app lives alongside them — not the other way around.
